# Ray Tracing in Python

This project is based on Peter Shirley's [Ray Tracing in One Weekend](https://raytracing.github.io/books/RayTracingInOneWeekend.html), but written in Python. Some of the functions have been refactored to work better in Python. For example, 'hit_record' is returned by various functions instead of mutating a passed-in record. The math was translated directly from the C++ original.

I want to create a terminal or web app down the line to facilitate user generated ray traced images, and I also want to write better documentation and comments for the code. 

Currently, the project is at part 9, Diffuse Materials.
